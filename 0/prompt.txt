# Gravespeaker
**Every stone has a story. Let it speak.**

*Photograph a headstone. Discover a life. Hear the story the records left behind.*

**Project:** Hacktoberfest 2026, Week 4: Ghost in the Machine  
**Deadline:** October 31, 2026, 11:59 PM PDT  
**Status:** Pre-development / MVP planning

## 1. Vision

Gravespeaker is a mobile-friendly web application that brings historical lives back into focus.

Users photograph a gravestone or upload an existing image. AI extracts identifying details, searches publicly accessible historical records, and reconstructs the deceased person's story in first person, as though they're speaking from beyond the grave.

The experience should feel mysterious and personal while remaining historically responsible.

**Core principle:** Resurrect the story, not invent the person.

## 2. MVP User Journey

1. **Capture or upload:** Photograph a gravestone or select an existing image.
2. **Identify:** AI extracts names, dates, inscriptions and other useful information. User can review and correct the results.
3. **Research:** Search obituaries, cemetery records, historical archives and indexed public information.
4. **Verify:** Cross-reference names, dates and geographic details. Allow the user to confirm an uncertain identity.
5. **Resurrect:** Generate a short, first-person historical narrative grounded in verified records.
6. **Explore:** Display source links and distinguish documented facts from AI reconstruction.

If credible information cannot be found, acknowledge the limitation. Never fill historical gaps with fabricated claims.

## 3. Technical Direction

| Component | Preliminary choice |
|---|---|
| Frontend | Svelte + Vite, responsive web |
| Backend | Node.js / TypeScript |
| AI orchestration | Mastra |
| Vision and OCR | Gemma 4 via Google Gemini API |
| Historical search | SerpApi |
| Narrative generation | Gemma 4 |
| Hosting | Google Cloud Run |
| Optional narration | ElevenLabs |
| Builder | Claude Code |
| Development tracking | Entire |

Keep components replaceable, particularly model inference and search providers.

No self-hosted models unless benchmarks demonstrate a compelling advantage.

## 4. Key Engineering Challenges

**Headstone recognition**
- Weathered stone, damaged inscriptions, shadows, unusual typography and partial dates.
- Evaluate actual recognition accuracy rather than assuming a vision model performs well.

**Historical identity resolution**
- Common names, incomplete records, contradictory dates and similarly named individuals.
- Use multiple identity signals and explicit uncertainty. Never silently combine different people's histories.

**Source discovery and reliability**
- Public availability does not guarantee unrestricted reuse.
- Respect access restrictions, provenance, licensing and unavailable records.
- Every substantive historical claim must be traceable to supporting evidence.

**First-person storytelling**
- Atmospheric and engaging without inventing relationships, events, memories, thoughts or emotions.
- Clearly label narratives as AI-generated historical reconstructions.
- Exclude unnecessary sensitive details about living individuals.

**Model selection**
- Benchmark Gemma 4 against a closed Gemini model on identical test inputs.
- Evaluate OCR accuracy, factual grounding, unsupported claims, latency and cost.
- Consider specialized open OCR only if testing supports the additional integration.

## 5. Open Innovation and Challenge Alignment

The open-weight model must meaningfully contribute to the finished application, not exist merely for challenge eligibility.

**Thesis for the DEV post:**

> The value of open innovation isn't that we refused to use closed AI. It's that we could independently test, choose, and improve the technology instead of accepting one provider's answer as the only option.

Document where the open approach performs better, matches a closed alternative, or exposes tradeoffs. Support conclusions with actual benchmarks and reproducible examples.

Focus the post on the problem, engineering decisions, real discoveries, failure cases and the value of making forgotten histories more accessible.
